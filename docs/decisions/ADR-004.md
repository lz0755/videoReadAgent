# ADR-004 M5 本机服务接入

M4 的锁文件没有 HTTP 服务和页面依赖。M5 单独引入 FastAPI、Uvicorn、python-multipart 和 Streamlit，继续使用 Python 3.14 及已有媒体依赖。首次解析锁定 FastAPI 0.165.0、Starlette 1.10.0、Uvicorn 0.54.0、python-multipart 0.0.34、Streamlit 1.67.0。与 M4 锁文件逐包比对，原有包的版本均相同。

API 使用本机请求令牌，经 Authorization 请求头传递。上传使用 multipart 的 file 和 authorization 两个字段。实际文件最大 524288000 字节，请求体另允许 65536 字节封装开销。服务端生成文件位置。浏览器端与 Streamlit 服务端把上传入口限制在 64 MiB。页面的媒体导航只有在浏览器能安全获取受控来源时才启用。

M2 的导入器曾占用计算用的 worker.lock，并在锁内清理自己的暂存。M5 需要在常驻 Worker 运行时也能导入。导入之间用同一把独立的 OS 导入锁保护配额检查和暂存清理。计算与离线迁移继续使用原 worker.lock，迁移前关闭所有写入口。HTTP 和 Worker 打开已初始化的数据库。复用已有导入授权回执、真媒体探测、原子发布及 M1 幂等事务。
